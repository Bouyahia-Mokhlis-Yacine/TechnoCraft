# Integrate the validated SATIM engine into TechnoCraft

## Summary

- Package the validated Python engine, frozen V1–V4 configurations and an atomic, versioned snapshot adapter.
- Serve frozen V2 predictions consistently in the dashboard, API and 711-row submission. Display collective V3 warnings, V4 investigation candidates and contactless evidence independently.
- Reuse the existing interface and review ledger while connecting model lifecycle, B4 explanations, operational triage, compound impact, forecasts, deterministic planning and printable reports to the shared snapshot.

## Verification

- Reproduced both sealed digests across 280 development rows and all 711 official keys on the pinned Windows Conda runtime.
- Compared advisory-enabled and advisory-disabled submission files byte for byte.
- Passed 84 original Python tests, seven snapshot integration tests, TypeScript, ESLint and a production build.
- Verified local Chrome dashboard, merchant, transaction, intelligence, alert, review and reporting journeys. Checked review version conflicts, API parity, the offline assistant, CSV/PDF exports and responsive widths.

## Limits

This is a replay of the organizer's historical archive. The optional private HPC connection and exact Linux submission parity were outside verified coverage. Real authorization telemetry, production identity and business cost assumptions still require SATIM input. The mentor absolute-value amount policy remains explicitly opt-in.
